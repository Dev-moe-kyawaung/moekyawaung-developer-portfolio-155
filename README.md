## 📝 Description

This repository hosts the **DevForge AI Studio**, a cutting-edge, cross-platform mobile and web application built with React Native and Expo. It serves as an all-in-one developer productivity platform, offering a suite of AI-powered tools to streamline the creation of high-quality documentation and assets for your software projects.

Instead of being a traditional developer portfolio, this project *is* the tool that helps developers forge their *own* star-worthy repositories. It provides intuitive interfaces for generating READMEs, GitHub profiles, badges, file trees, licenses, changelogs, and social cards, all with context-aware AI assistance and live previews.

## ✨ Key Features

DevForge AI Studio offers a comprehensive set of tools to enhance your project's presentation and documentation:

*   **README Forge**: Create dynamic, block-based README.md files with AI assistance, tailored to your project's tech stack and features. Includes live GitHub-styled previews.
*   **GitHub Profile Studio**: Design a compelling GitHub profile README with animated typing banners, dynamic stats cards, top languages, and custom tech badges.
*   **Badge Smith**: Generate custom Shields.io badges with a vast library of logos, customizable colors, and various styles, all from an intuitive interface.
*   **File Tree Architect**: Visualize your project's directory structure in clean ASCII or Unicode format, with presets for common architectures like Next.js App Router, Clean Architecture, React Native, and FastAPI.
*   **License Selector**: Easily choose and generate appropriate open-source licenses (MIT, Apache, GPL, BSD, MPL, Unlicense) with automated copyright year and author insertion.
*   **Changelog Generator**: Draft structured `CHANGELOG.md` files following Conventional Commits and Semantic Versioning, categorizing features, fixes, performance improvements, and breaking changes.
*   **Social OG Card Maker**: Create eye-catching 1280x640 Open Graph (OG) social preview images for your repositories, with customizable themes, project details, and stats.
*   **DocSprint & Architecture Generator**: Quickly generate Mermaid.js diagrams (flowcharts, sequence, ER), environment variable tables, and API endpoint reference tables for detailed technical specifications.
*   **AI Assistant**: Leverage context-aware AI to generate initial content for any of the tools, speeding up your documentation process.
*   **Cross-Platform UI**: Access the full suite of tools on web, iOS, and Android, thanks to its Expo/React Native foundation.
*   **Local Project Storage**: Save and manage your generated assets as drafts directly within the studio using local storage.
